# v0.1.0 — リリース説明の下書き

GitHub Releaseやタグはまだ作成していません。

owndappは、ローカルの開発プロジェクトを見つけて登録し、依存パッケージの脆弱性への対応を記録するツールです。Node.js 24.14以降を導入済みの開発者向けに、ターミナルから起動してブラウザで使います。

## 主な機能

- 再開できるフォルダ探索と、候補の選択登録
- カタログの一覧・フォルダ別表示、アーカイブと探索除外
- npm/Yarn/pnpm・Composer・Python・Cargoの依存読み取りと検索
- 送信前に確認できるOSV照会、優先度と対策メモ、アプリ単位の対応状況
- Takumi Guardの個別設定

## 対応状況

macOS / Apple Siliconで導入と操作を検証しています。Windowsはパス入力による試験的対応で、実機での導入・権限・再起動などの受け入れ確認は未完了です。Windowsのフォルダ選択や外部アプリ起動は提供しません。

未対応形式や読み取っていない構成、実際のデプロイ済み版、未知の脆弱性までは判定しません。自動的なパッケージ更新やクラウド操作は行いません。
