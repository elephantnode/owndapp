# 検証記録

2026-10-26。公開用ソースの準備時点で確認した範囲です。実際のプロジェクト名・フォルダ・カタログを含む過去の内部検証ログは公開用コピーへ持ち込んでいません。

## 確認したこと

- macOS / Apple Silicon、Node.js 24.14でWindows対応までの単体・API194件が成功。
- ビルド警告の限定除外テストを含む195件が、公開コピーの匿名化後にNode.js 24.14でも成功。
- TypeScript型検査、本番ビルド、分割バンドルによるChromeのブラウザ操作16件が成功。
- 読み取り境界・symlink除外、探索の保存/再開、登録、依存検索、重大度取り込み、対応状況、アーカイブ/除外、選択読み取りを生成fixtureで検証。
- Cargoは対応するlock形式とworkspace・取得元をfixtureで検証。実際の配布済み版やfeaturesの到達可能性は判定しない。
- Windowsのパス処理と能力別UI/APIはmacOS上で模擬検証。Windows実機/実GitHub runnerでの導入・権限・ジャンクション等は未確認。
- 新規導入の検証範囲は[導入検証](install-verification.md)、Windowsの残項目は[Windows手順](windows.md)を参照。

## 公開時の確認

公開用コピーの例示パスを匿名化した後も、195テスト・型/本番ビルド・Chrome16件を隔離環境で確認した。GitHub CIの実行結果はpush後に別途確認する。設定ファイルを用意したことを実行成功の代わりにしない。
