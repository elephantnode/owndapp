# owndapp マニュアル

自分で作ったアプリをまとめて管理し、使っているパッケージの既知の脆弱性をチェックするためのマニュアルです。上から順に読めば使い始められます。

1. [はじめる](01-getting-started.md)：インストールして起動する
2. [アプリを登録する](02-register.md)：フォルダから自分のアプリを見つけて登録する
3. [脆弱性をチェックして対応する](03-check-and-fix.md)：チェックして、重大なものから直す
4. [アプリを整理する・探す](04-organize.md)：一覧の見方、まとめて変更、片付け、依存検索
5. [困ったとき](05-troubleshooting.md)
6. [アンインストール](06-uninstall.md)

細かい条件や仕組みは、開発者向けの[機能と対応範囲](../reference/features.md)にあります。普段使うぶんには読まなくてかまいません。
