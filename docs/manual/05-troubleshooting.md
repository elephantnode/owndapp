# 困ったとき

まず owndapp のフォルダで `npm run doctor` を実行してください。何が足りないかを教えてくれます（読むだけで、何も変更しません）。

| 困っていること | すること |
| --- | --- |
| Node.js の版が古いと言われる | Node.js 24.14 以降を入れます |
| 画面が出ない | `npm run build` を実行してから `npm start` |
| 「ポート4310は使用中です」と出る | owndapp がもう起動していないか確認します。別の番号で起動するなら `OWNDAPP_PORT=4311 npm start` |
| 登録したアプリが消えた | 保存先を変えていないか確認します（`npm run doctor` に表示されます） |
| フォルダ選択の画面が出ない | 画面は owndapp を起動した Mac に出ます。Windows ではパスを入力します |
| アプリが「フォルダが見つかりません」になった | フォルダを移動・削除した場合です。「登録したアプリ」の上に出る「カタログから外す」で整理できます |
| チェックが「一部のみ」になる | 通信に失敗したか、読めないファイルがあります。少し待ってもう一度チェックします |

それでも解決しないときは、[運用ガイド](../reference/operations.md)の詳しい手順を見てください。
