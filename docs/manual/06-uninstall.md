# アンインストール

owndapp はフォルダの外にプログラムを入れないので、フォルダを削除すればアンインストールできます。登録したアプリのソースには影響しません。

1. 起動したターミナルで `Ctrl` + `C` を押して止めます。
2. 記録を残したい場合は、owndapp のフォルダの中の `.owndapp` フォルダをコピーしておきます。
3. owndapp のフォルダをゴミ箱に入れます。

## 残るもの

- 別に入れた Node.js と osv-scanner。不要ならそれぞれアンインストールします。
- Takumi Guard を設定したアプリの `.npmrc` の設定。元に戻す方法は [Guard の運用](../reference/takumi-guard.md)にあります。

保存先を `OWNDAPP_DATA_DIR` で別の場所にしていた場合は、そのフォルダも削除してください。ほかに残るものの一覧は[運用ガイド](../reference/operations.md#アンインストール)にあります。
