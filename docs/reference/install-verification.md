## 警告と検証範囲

- 署名検証はTUFからの鍵取得に失敗したという警告の後、Guardから鍵を直接取得して成功した。追加のHTTPログでauditのPOST成功とGuardの鍵エンドポイントを確認。これはTUF経路の成功を意味しない。
- Node.js24.14.0ではnode:sqliteのExperimentalWarningが出た。初回DB作成と再起動は成功した。
- ビルドでは依存の `use client` 指示に関する警告が出る。静的画面の生成と操作は成功した。
- 検証はmacOSのApple Silicon上。Intel Macや他OS、全Node.js版を検証したものではない。
- 新しい配布元からのダウンロードは未確認（配布元未決）。Finderの実ダイアログ操作は自動テストで代替しているため、この工程では未検証。
- 公開レジストリの脆弱性情報と署名の検査結果は実行時点のもの。未知のマルウェアがないことや、Guardを全通信が通ることを保証しない。
